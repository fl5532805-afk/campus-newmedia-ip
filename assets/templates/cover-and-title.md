# 封面与标题公式

> 封面是信息流第一帧，0.5秒决定他停不停。核心不是好看，是**可识别 + 精准人群 + 一句话痛点**。

## 一、封面三要素

1. **统一模板**：固定字体、配色、排版、人物位置、署名位置。全部封面用同一个模板，刷到就认出你。
2. **大字主文案**：6-10个字，来自钩子句；数字、恐惧词、人群词高亮（如"招不到人""90%""三件事"）。
3. **人物/场景**：真人近景优先，表情与情绪匹配（焦虑/认真/犀利）；背景是你的真实经营场景。

## 二、恐惧获客封面句式（本方法论主打）

| 句式 | 示例 |
|---|---|
| 人群+普遍痛点 | 做驾校的老板，今年普遍招不到人 |
| 数字冲击 | 90%的校园生意，都死在这一步 |
| 反常识 | 不是学生少了，是你的打法废了 |
| 后果预警 | 再等三个月，你连汤都喝不到 |
| 确定性动作 | 招不到人，就做这三件事 |
| 提问点名 | 你还在靠传单招学员？ |

## 三、标题公式

- 恐惧型：【人群】今年普遍【痛点】，很简单，就因为【反常识原因】
- 算账型：【一个动作/一套系统】，一个月多【可验证结果】，他做对了什么
- 案例型：【身份】用【时间】做到【结果】，关键是这3件事
- 避坑型：【人群】最容易踩的【数字】个坑，第【】个90%的人都犯
- 话题标签：#校园经济 #获客 #【行业】 + 精准地域词（如#长沙）

## 四、视觉风格锚点（帆总账号）

- 风格：黄黑撕纸纯文字封面 / 橙胶囊标签 + 毛笔字 + 粉笔画点缀。
- 署名：固定角落放 @帆总不累。
- 正文字号占封面宽度约 1/2 以上，手机端缩略图也能看清。
- 同一批内容保持同色系；行业不同可换主色，但版式不变。

## 五、封面检查清单

- [ ] 0.5秒内看清"这条是给谁看的"
- [ ] 主文案与钩子、内容一致（不是标题党）
- [ ] 无极限词、无承诺词（过合规）
- [ ] 模板/字体/署名统一
- [ ] 缩略图状态下大字依然清晰
