# 选题库（建库模板）

> 保持库里始终有30条储备，拍完划掉，每周补新。免费版给母题+3条成品；30+成库属付费交付。

## 一、母题清单（三核生根）

### 真实感（只有我能讲）
1. 【低谷复盘：如"我开驾校第一年差点倒闭"】
2. 【情绪共鸣：如"今年招不到人的那种焦虑"】
3. 【不完美自曝：如"我第一次拍视频有多尬"】
4. 【真实日常：如"驾校老板的一天"】
5. 【识人踩坑：如"我招过的最坑的合伙人"】

### 专业度（只有做过的人才知道）
6. 【案例拆解：如"这个学员为什么45天拿证"】
7. 【数据说话：如"今年咨询量为什么跌了一半"】
8. 【实力展示：如"我的训练场实拍"】
9. 【行业洞察：如"学生选驾校的决策路径变了"】
10. 【实操方法：如"新手练科二最容易挂的3个点"】

### 价值供给（看完立刻能用）
11. 【方法干货：如"选驾校避坑3问"】
12. 【工具资源：如"报名前必看的费用清单"】
13. 【问题解决：如"挂科了怎么办"】
14. 【案例预览：如"一个线上起号的驾校做对了什么"】
15. 【行业话术：如"顾问怎么报价不被砍价"】

## 二、六维裂变表（对母题横向扩展）

| 维度 | 本账号的选项 |
|---|---|
| 形式 | 口播/跟拍/学员访谈/图文/直播切片 |
| 受众细分 | 新手学生/家长/同行老板/不同区域 |
| 决策场景 | 认知（不知道选驾校要先看线上）/搜集（比价）/评估（看口碑）/决策（怕被坑）/服务（学车中） |
| 时机 | 开学季/寒暑假/政策节点/日常 |
| 深度 | 知识层（是什么）/经验层（怎么避坑）/认知层（行业变化） |
| 情绪 | 恐惧/好奇/共鸣/爽感/愤怒 |

## 四、批量生成
把母题与六维选项填入 brief.json，运行：
```bash
python3 scripts/topic_matrix.py --brief brief.json
```
每条选题按"钩子+痛点+解决方案+行动号召"四要素检查，再进入脚本模板。
