# 定位画布（填空模板）

> 用法：复制本文件，把【】替换成真实信息，逐项填写后做自洽检验。

## 基本信息
- 行业/赛道：【如：长沙本地驾校】
- 出镜人：【如：驾校老板本人，从业8年】
- 产品与报价：【如：C1驾照培训，客资口径=私信留电话】
- 发布平台：【抖音/小红书/视频号】
- 目标：【每月获取X条有效客资】

## 定位三问
1. 观众为什么关注我：【我能持续提供什么价值】
2. 我帮谁解决什么问题：【身份+痛点+场景】
3. 我靠什么赚钱：【主变现路径+副路径】

## 六要素
| 要素 | 填写 |
|---|---|
| 身份标签（职业+差异化） | 【一句话，忌泛标签】 |
| 赛道（大赛道+小切口） | 【市场容量/变现效率/政策安全】 |
| 目标受众（身份/痛点/场景） | 【具体到能画出一个人】 |
| 变现路径（七种选1-2） | 【带货/招商/培训/品牌溢价/政企/toB/分发】 |
| 内容调性 | 【沉稳/犀利/亲切/幽默，选一个锁定】 |
| 视觉风格 | 【封面模板/固定场景/调色/字幕/形象】 |

## 三核素材清单
- 真实感：3个高峰【】、3个低谷【】、3个不完美/踩坑【】
- 专业度：3个可验证案例【】、3组真实数据【】、3个硬实力证明【】
- 价值供给：3个免费方法/工具【】、1个付费承接产品【】

## 一句话定位
【我是谁，专门帮谁，解决什么问题，凭什么是我】

## 内容配比（账号级）
- 引流款40%：【主要选题方向】
- 信任款30%：【主要选题方向】
- 变现款20%：【主要选题方向】
- 人设款10%：【主要选题方向】

## 自洽检验（逐条打勾）
- [ ] 三问互相支撑，变现路径匹配受众
- [ ] 六要素闭环，没有矛盾
- [ ] 差异化一句话能说清
- [ ] 素材每天都在产生
- [ ] 合规风险已排查
