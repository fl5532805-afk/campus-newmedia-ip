## 1. 内容矩阵

- **形式矩阵**：同一选题→口播、图文、直播切片、跟拍，花一次打磨的时间做多种内容。
- **平台矩阵**：抖音、视频号、小红书、快手、B站，一稿多发，标题/封面按平台调（小红书重图文与标题、抖音重钩子、视频号重熟人社群）。
- **深度矩阵**：知识层30秒短视频拉新 → 经验层实操建信任 → 认知层深度/直播建壁垒。
- **账号矩阵**：老板本人IP号 + 业务号/项目号 + 学生/团队切片号，形成多账号导流。
- 内容配比（账号级）：引流40% / 信任30% / 变现20% / 人设10%。

## 2. AI 工业化内容生产

核心模型：**方法论是弹药，AI 是放大器**。先有自己的核心资产（书/SOP/方法论），AI 才有东西可拆。
1. 把方法论沉淀为一个核心文档（如五过程框架、行业SOP）。
2. 按章节拆成选题母题，再六维裂变出几百条选题。
3. AI 批量产初稿（每条只讲一个点），人工审核改语感、校事实。
4. 每条视频=24小时在线的"无人售货员"，只讲一个方法点，不直接推销。
5. 日产3-10条，多账号分发，评论区/主页统一引导。
铁律：AI 产稿必须人工过一遍，真实案例和数据必须核实；AI 不负责承诺，只负责表达。

## 3. 流量闭环六环节

任何内容与动作都必须能对应到闭环中的某一层：

| 环节 | 载体 | 动作 | 流向 |
|---|---|---|---|
| 曝光 | 短视频/直播 | 按五过程持续产出 | 主页/粉丝群 |
| 钩子 | 资料包、选题表、智能体试用、书的电子版 | 评论区/私信只导粉丝群 | 粉丝群 |
| 承接 | 粉丝群/低价社群 | 持续给价值、案例复盘、免费诊断 | 产品 |
| 自助 | 低价工具/AI智能体/99元SOP | 低预算客户自助起号 | 效果不佳者升级 |
| 成交 | 代运营/陪跑/系统服务 | 私聊报价、合同、交付 | 案例口碑 |
| 交付裂变 | 学员/合伙人/楼长/团长 | 本地交付与分销，产生新案例 | 反哺曝光 |

转化率按"曝光→进群→低价→付费服务→高客单"五级口径记录；首月不设硬性目标，先跑通基线。

## 4. 产品阶梯（每层都为下一层导流）

| 层级 | 形态（示例） | 角色 |
|---|---|---|
| 锚点 | 免费资料/电子SOP/实体书（39.9-49.9） | 内容弹药与引流钩子 |
| 入门 | 99元AI获客SOP/智能体（行业版999，待定价） | 低门槛筛选与工具绑定 |
| 订阅 | 399/498 社群或读书会 | 信任沉淀、续费池 |
| 高客单 | 起号3000/次；单号代运营4500/月起；矩阵900/账号/月 | 标准化营收主力 |
| 塔尖 | 老板陪跑/1v1定位（不公开报价，私聊） | 高利润+标杆案例 |
| 分销 | 认证讲师/合伙人/学生团长 | 本地交付与销售网络 |

原则：
- 前台只卖三个品，避免选择困难；塔尖不公开报价。
- 只承诺客资数量与口径，不承诺结果（见 `compliance.md`）。
- 书里/资料里埋社群钩子，社群里埋服务钩子，服务客户里筛讲师，形成闭环。

## 5. 开源 Skill 的引流设计（本 Skill 的分发与转化）

本 Skill 本身就是锚点层产品，遵循"免费使用→流量曝光→付费升级"：
- **开源层给什么**：五过程框架、恐惧获客钩子公式、四段式脚本模板、封面标题模板、合规检查、每次3条选题。
- **开源层边界（故意留边界）**：不带行业案例库、不批量给30+选题库、不做1v1定位诊断、不含行业违禁词深度包、不承诺客资。
- **署名**：输出末尾默认保留"由 @帆总不累 校园新媒体获客方法论 Skill 生成"，这是免费使用者对方法论来源的标注。
- **软转化（不硬塞微信）**：①输出结尾提示"需要完整选题库/行业案例库，进主页粉丝群"；②功能边界即广告（"30条选题库与1v1定位属于付费交付"）；③README/发布页放免费资料领取方式。
- **分发渠道**：GitHub（主阵地）、Gitee（国内）、智能体广场（豆包/扣子/Dify）；把"如何安装、如何用这个 Skill 一条指令生成三套脚本"拍成教程视频，发布过程本身即获客内容。
