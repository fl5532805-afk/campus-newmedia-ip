## 1. 注意力曲线与四段式

- 0-3秒生死线：超60%的人3秒内划走。
- 3-15秒期待线：再流失30-40%，要制造期待。
- 15秒-结尾价值线：给干货（占60-70%时长）。
- 最后5秒行动线：给行动理由。

四段式：**5秒钩子 → 矛盾冲突 → 干货内容 → 价值互动**。

## 2. 四段逐段写法

### 第一段：5秒钩子（3-5秒）
- 第一句话必须是钩子，禁止"大家好我是XX"类铺垫。
- 不是让所有人停下来，是让**目标受众**停下来。精准击中目标受众比让所有人都感兴趣重要100倍。
- 钩子不是标题党：允许夸张/反常识/有冲击力，但必须真实且与内容匹配。
- 钩子写法见 `02-topic-system.md` 第4节。

### 第二段：矛盾冲突（3-15秒）
制造"想知道后面怎么说"的期待。常用三种矛盾：
- 常识与真相的矛盾："所有人都在说X，但追热点的账号90%都做不大"。
- 理想与现实的矛盾："你以为学了方法就能起号，其实你死在第一步"。
- 群体差异的矛盾："同样做驾校，有人30个学员有人300个，差的不是位置"。

### 第三段：干货内容（15-50秒，占60-70%）
- 给方法、给步骤、给数字、给可操作的东西。用"第一/第二/第三"结构。
- 一个案例打透：具体场景+具体动作+具体结果。
- 恐惧获客类：先把"不解决的后果"讲透（让他怕），再给你的解法（让他觉得你能救）。
- 口播每3-5秒给一个信息点，避免长句和书面语。

### 第四段：价值互动（最后5-10秒）
给行动指令，且只给一个主动作：
- 引流："评论区打出你的行业，我给你出一条选题"。
- 承接："想要这套选题表的，进我主页粉丝群，免费发"。
- 关注："关注我，每天拆一条校园获客的真实打法"。
- 不在字幕、评论区留微信号（合规），统一导粉丝群。

## 3. 口播语感（帆总口播指纹）

这套语感专门适配"传统行业老板+校园创业者"人设，写稿时逐条对照：

1. **设问开场**：用目标人群的行业现象起句，如"做驾校的老板，今年普遍都招不到人"。
2. **"很简单"反常识**：先给结论再拆原因，"很简单，不是学生少了，是你还在用十年前的打法"。
3. **拆群体心理**：把客户/同行/学生的行为心理拆给观众听，"你猜学生现在怎么选驾校？先刷抖音，看谁的号真实"。
4. **"当然不是让你……"堵误区**：先承认用户的本能反应，再堵掉错误做法，"当然不是让你去拍剧情跳舞，你一个老板拍那个只会掉价"。
5. **给确定性动作**："你就做三件事：第一……第二……第三……"。
6. **结尾行业钩子**："评论区打出你的行业，我给你出一条能获客的选题"。

语言要求：口语化、说人话、直接、不端着；禁用"家人们/宝子们"、书面语、正确的废话。

## 4. 一张二张三张：选题拆解

一个选题不要只拍一条，按认知递进拆成系列：
- 第一张（是什么+为什么）："什么是矩阵，为什么单账号做不大"。
- 第二张（分类/对比）："矩阵的三种模型，你适合哪一种"。
- 第三张（怎么做）："从0搭一个矩阵，我分五步走"。

## 5. 拍摄实操（手机即可）

- 场景：办公室实景、门店、客户现场、校园实地；固定2-3个场景，不影棚摆拍。
- 机位：手机固定/手持，自然光，胸口以上近景，眼睛看镜头。
- 口播模板：不写逐字稿也可，用"关键词提词卡"（钩子关键词+3个动作点+结尾指令），每段不超过3行。
- 镜头语言：重点处加手势、身体前倾；重点句加放大字幕；B-roll补手机操作/门店/数据画面。
- 人物：商务休闲、精神；不穿西装打领带（像销售）、不背心拖鞋。
- 形象红线：真实感是第一护城河，但不要杂乱环境、敏感信息入镜。

## 6. 封面与标题

- 封面是信息流第一帧：统一模板（固定字体/配色/排版/人物位置），0.5秒认出你。
- 封面主文案=钩子的口语化，大字（6-10字最佳），数字和恐惧词高亮（如"招不到人"）。
- 标题公式与模板见 `assets/templates/cover-and-title.md`。

## 7. 内容避坑

1. 前3秒铺垫自我介绍（直接枪毙）。
2. 全片观点没有方法（听完很激动，啥也没拿走）。
3. 钩子与内容不符（标题党，完播崩）。
4. 同时给多个行动指令（观众不知道干什么）。
5. 书面语/长句/端着讲（口播要像跟朋友说话）。
6. 只讲成功不讲真实（缺真实感，像广告）。

## 8. 从选题到脚本的流程（30分钟）

1. 从选题库取1条母题，确认它的核心目的（引流/信任/变现）。
2. 用黄金公式列四要素关键词（钩子句、痛点句、3个动作点、行动指令）。
3. 按四段式写逐字稿，套 `assets/templates/script-template.md`。
4. 口语化通读一遍，把所有书面词改成大白话。
5. 跑 `scripts/check_compliance.py` 合规扫描，改到0命中。
6. 配封面文案、拍摄提示、评论区引导语。

> 每次默认产出三套不同角度（恐惧型/算账型/案例型），成品参考 `assets/examples/`。
