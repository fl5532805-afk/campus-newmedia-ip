# 07 · 行业恐惧获客 Playbooks

> 本方法论最能打的钩子类型。获客不要拼命展示"我有多专业"，要去**放大他的恐惧**。
> 底层逻辑：**大多数人不会为"更好"买单，但一定会为"不这样做就会更惨"而付费。**

## 1. 心理学原理

- 修手机的师傅拿到手机先叹口气："问题大了，主板都坏了，再拖数据都找不回来。"——你立刻想掏钱修，因为你怕了，后果你承担不起。
- 获客同理：不要先证明"我很好"，要让他看见"这个问题不解决，后果是什么"。恐惧制造行动，专业给他出路。
- 适用对象：传统行业老板、行业正在萎缩/内卷/被新模式淘汰、有预算但不知道怎么获客的人。
- 注意：恐惧是入口，不是终点。**吓完必须给希望、给确定性动作**，否则只有情绪没有转化，还可能违规。

## 2. 恐惧型脚本五段公式

1. **现象（设问开场，他正在经历）**："做驾校的老板，今年普遍都招不到人，对吧？"
2. **"很简单"反常识归因**："很简单，不是学生少了，是你还在用十年前的打法。"
3. **拆群体心理（他的客户已经变了）**："你猜学生现在怎么选驾校？不看门店、不看传单，先刷抖音，看谁的号真实、学员评论多。"
4. **放大不解决的后果 + 堵错误做法**："你再等三个月，周边那几家年轻老板把线上账号做起来，你连汤都喝不到。当然不是让你去拍剧情跳舞，你一个老板拍那个只会掉价。"
5. **给出路（3个确定性动作）+ 行动号召**："你就做三件事……评论区打出你的行业，我给你出一条能获客的选题。"

## 3. 恐惧的尺度（合规边界）

- 恐惧必须真实、具体、与他的生意相关，禁止编造行业崩盘、造谣政策。
- 可以说"打法失效、生源在流失、同行在抢"，不可以说"不做就倒闭/血本无归"等绝对化恐吓。
- 不贬低具体同行（不点名、不踩某家）。
- 必须给希望和可执行动作；结尾必须有出路。
- 驾培/教培/单招：不承诺包过/录取/内部名额（见 `compliance.md`）。
- 恐惧的落点是"换打法"，不是"交钱给我"；先给方法，再在评论区/粉丝群承接。

## 4. 行业恐惧清单

### 驾校 / 驾培
- 现象：门店客流下降、传单没人看、地推代理模式失效。
- 恐惧：学生选驾校先刷抖音；同行年轻老板线上起号后，本地流量被截胡；淡季现金流断裂。
- 错误做法：降价打价格战、继续发传单、让员工尬跳剧情。
- 出路：老板本人出镜讲学车真实过程/学员避坑/本地训练场实拍；做"学员视角"选题；短视频引导私信留资。

### 劳务 / 招工 / 人力
- 现象：靠熟人转介绍，招工越来越难；年轻人不进中介门店。
- 恐惧：工厂单子来了没人可派，赚不到人头费；黑中介名声连累正规机构；抖音上招工号已在抢人。
- 错误做法：只发"月薪过万"大字报（像骗子、限流）、不拍真实厂区宿舍。
- 出路：实拍厂区/宿舍/食堂/发薪记录（授权）；讲工人最关心的真话；用"反套路避坑"建立信任。

### 教培 / 单招 / 升学
- 现象：季节性招生、留资成本高、内容同质化。
- 恐惧：家长信息获取全部线上化，没账号=不在家长的候选名单里；错过招生季等一年。
- 错误做法：承诺包过/录取/内部名额/原题（违规）、贩卖焦虑过度。
- 出路：讲政策解读、志愿填报常识、真实上岸案例（授权）；只承诺客资不承诺结果。

### 校园零食仓 / 外卖 / 跑腿（含系统服务商）
- 现象：传统校园超市/代理模式受线上楼店冲击；创业团队不会放大。
- 恐惧：学生消费习惯已经在小程序里；你管的楼越多越累，不会用系统就被会用系统的人整合。
- 错误做法：自己囤货打包全包、靠人工记账、不建楼长分销。
- 出路：讲"楼长自营+抽成+系统管理"模式；用真实战报（如开学一个月160个楼长、每天抽成200+，案例需授权）。
- 系统服务商面向的是"已经做起来、需要放大"的学生团队，恐惧点是"你一个人干到天花板，别人在复制楼长"。

### 运营商 / 电话卡 / 校园渠道
- 现象：线下摆摊转化差、代理难管理。
- 恐惧：开学季窗口期只有几周，线上没布局，一年最大的一波流量白白错过。
- 出路：把代理转成楼长/团长、线上招募内容化、系统管理分销。

### 代运营 / 新媒体服务（获同行/老板客户）
- 现象：老板想转型但不会做、怕被代运营坑。
- 恐惧：自己招人做半年没起号、工资照发；被不靠谱代运营收了钱不交付；同行已经跑出来。
- 错误做法：老板只听课不动手、追求完美迟迟不开拍。
- 出路：先给免费诊断、晒真实案例数据（授权）、用"我做给你看再带你做"。

### 宠物上门喂养 / 遛狗（本地服务）
- 现象：节假日刚需，主人怕陌生人上门、怕跑路。
- 恐惧：把猫留给不靠谱的人，钥匙/监控/宠物安全全是风险；假期一到一将难求。
- 错误做法：只发价格不拍过程、不露脸不实名。
- 出路：全程记录喂养过程、实名背书、服务SOP可视化、老客户好评；内容在小红书/本地群承接。

## 5. 钩子句库（按行业替换）

- 现象句："做【行业】的老板，今年是不是普遍【他的痛】？"
- 归因句："很简单，不是【表面原因】，是【真正原因】。"
- 心理句："你猜你的客户现在怎么选？不看【旧渠道】，先刷【新渠道】。"
- 后果句："你再等【时间】，【同行/新玩家】就会把【他最在乎的东西】抢走。"
- 误区句："当然不是让你去【错误做法】。"
- 出路句："你就做三件事：第一……第二……第三……"
- 行动句："评论区打出你的行业，我给你出一条能获客的选题。"

> 三套成品脚本见 `assets/examples/`（恐惧型-驾校 / 算账型-劳务 / 案例型-代运营）。
