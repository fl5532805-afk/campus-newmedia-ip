# 合规红线（强制门）

> 每条脚本/文案/封面/评论区话术，发布前必须过本文件 + 跑 `scripts/check_compliance.py`。
> 原则：内容可以放大恐惧、可以营销，但不承诺结果、不造假、不碰敏感、不诱导私下交易。

## 1. 承诺类红线（最常犯）

一律不允许出现：

- 驾培/教培/单招：包过、保过、必过、100%通过、不过退款、内部名额、内部指标、原题、包录取、保录取、稳上、交钱就能上。
- 通用：稳赚、必赚、躺赚、零风险、暴富、年入百万、月入X万保底、包回本、保证成交。
- 替代说法：
  - 对外只承诺**客资数量与口径**（如"留电话/私信留资/到店"），统一表述为"留资/客资"，不说"成交/报名"。
  - 用"去年我们的学员里，有X位做到了……（有授权可查）"，不用"你也能"。

## 2. 极限词与广告法

- 禁用：最、第一、唯一、首选、顶级、国家级、世界级、绝对、永远、100%、全网最低。
- 数字必须真实可验证：单数、人数、收益、时间都要有来源，不编。
- 对比不点名、不贬低具体同行/地区/行业。

## 3. 真实与案例

- 案例必须真实，本人或客户**书面授权**；未授权一律匿名化（去掉学校、姓名、公司名）。
- 不摆拍、不虚构助农/滞销/公益；不把别人的事安在自己身上。
- 收益截图、发薪记录、后台数据需授权，且打码敏感信息。
- 客户隐私（手机号、姓名、住址、订单）绝不入镜。

## 4. 平台与私域引流

- 字幕、口播、评论区不留微信号/手机号（会限流、违规）。
- 统一引导："进我主页粉丝群"；私信承接也先进群。
- 不发"加微信发资料"、不刷评论、不诱导虚假互动。

## 5. 行业敏感与正能量红线

- 不碰在职领导干部、政治、宗教、民族、敏感事件；不绑定争议人物。
- 不做行业纠纷站队、不晒债务讨债。
- 不贬低其他地区和行业。
- 强监管领域（驾培、教培、单招、医疗、金融、法律）：只做内容结构与获客方法，专业表述由持证方审核。

## 6. 交易与资金安全

- 不收高额押金、不扣押证件、不诱导贷款。
- 不承诺"交押金给货源/给名额"式话术；代运营/陪跑合同写明客资口径与交付物，不写成交保底。
- 学生群体：不诱导透支、不夸大收益。

## 7. 发布前自查清单（逐条打勾）

1. 有无承诺结果类词（包过/保底/稳赚/录取）？
2. 有无极限词？数字是否真实可验证？
3. 案例是否授权/匿名？
4. 有无微信/手机号出现在字幕、评论区？
5. 有无敏感人物/话题/纠纷？
6. 恐惧内容是否给了希望和出路？
7. 是否跑过 `check_compliance.py` 且 0 命中？
