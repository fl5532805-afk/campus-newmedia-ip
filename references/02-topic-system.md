# 02 · 选题系统

> 五过程第二步。90%的人做不出爆款，死在选题这一步——不是没内容拍，是没有"无限选题系统"。
> 公式：无限选题 = 三核生根（内容本质）× 六维裂变（呈现放大）。

## 1. 第一步：三核生根

每个母题必须命中至少一个核心、有明确目的（拉流量/建信任/促变现）：

- **真实感（约15个母题）**：3个来源（真实经历/真实情绪/不完美）× 5个方向（低谷复盘/情绪共鸣/不完美自曝/真实日常/识人踩坑）。检验：这条是不是只有你能讲？
- **专业度（约45个母题）**：3个证明（案例/赚钱数据/硬实力）× 3个层次（知识/经验/认知）× 5个方向（案例拆解/数据说话/实力展示/行业洞察/实操方法）。检验：是不是"只有做过的人才知道"？
- **价值供给（约75个母题）**：3层价值（情绪/认知/实用）× 变现路径（培训/带货/toB/招商/政企）× 5个方向（方法干货/工具资源/案例预览/问题解决/选品测评）。检验：观众看完能不能立刻用？

一个母题可命中 1/2/3 个核心，共 7 种组合；**三核全中的是顶级选题**（一条同时拉流量、建信任、促变现）。

## 2. 第二步：六维裂变

对每个母题，用六个维度做横向扩展。三个生产端（形式/深度/情绪），三个消费端（人群/场景/时机）：

| 维度 | 选项 | 要点 |
|---|---|---|
| 形式 | 口播/跟拍vlog/访谈/剧情/图文/直播切片 | 选最有说服力的形式，不为换形式硬套 |
| 受众细分 | 认知阶段/行业场景/预算/决策角色/地域 | 细分到"有足够人群+共同需求"，太细没流量 |
| 决策场景 | 认知/信息搜集/方案评估/购买决策/使用复购 | 5条视频走完一个完整转化漏斗；认知阶段不卖货 |
| 时机 | 日常/节日节气/行业节点/热点/季节周期 | 热点只追与定位相关的，生命周期24-72小时，要快 |
| 深度 | 知识层（是什么）/经验层（怎么做）/认知层（为什么） | 0粉先做知识层、经验层，信任后再加认知层 |
| 情绪 | 恐惧/愤怒/焦虑/好奇/共鸣/爽感 | 恐惧和愤怒最易引发评论转发，但必须有内容支撑 |

一个母题理论上可裂变成几十上百个变体，且全部继承母题的"根"。
批量生成用 `scripts/topic_matrix.py`。

## 3. 爆款黄金公式

90%的选题只有"主题"没有"结构"。结构四要素，缺一不可：

| 要素 | 对应核心 | 60秒时长占比 | 任务 |
|---|---|---|---|
| 钩子 | 真实感 | 3-5秒 | 让人停下来，不划走 |
| 痛点 | 价值供给 | 5-15秒 | 精准击中焦虑，觉得"跟我有关" |
| 解决方案 | 专业度+价值供给 | 15-50秒（60-70%） | 给方法、步骤、工具，让人觉得专业有用 |
| 行动号召 | 变现路径 | 5-10秒 | 引导关注/评论/收藏/进群/咨询 |

逻辑链：钩子拉住人→痛点共鸣→解决方案给价值→行动号召让人行动。前一步没做好，后面再好也没用。

## 4. 七种钩子写法

1. **反常识断言**："【大众认知】其实【真相】"；"90%的人【错误做法】，其实【正确做法】"。必须真实、有论据。
2. **强共鸣提问**："你有没有过【具体场景】？"具体、与受众相关，忌"你知道吗"。
3. **痛点直击**：直接说出他最焦虑的事，"他怎么知道我在想这个"。
4. **数字冲击**：具体数字开场，"500个""37天""47次"；数字必须真实，"很多人"不如"500个"。
5. **悬念提问**：抛出具体问题，让人想知道答案。
6. **真实经历开场**：直接讲你的真实故事/搞砸的事，自带故事性、别人抄不走。
7. **结果前置**：先给结果再讲方法，"37天成了，关键做对三件事"。
8. **情绪爆发**：愤怒/心疼/焦虑开场，传播力最强；情绪必须真实，且后面必须有干货。

钩子三坑：与内容脱节（标题党）、太长（3-5秒内必须说完）、所有视频用同一种。

## 5. 批量生产法

- **母题补充**：先列母题，再用六维交叉补变体，10分钟补5-10条。
- **矩阵化生产**：同一选题多形式、多平台、多深度产出，一次生产多次使用。
  - 形式矩阵：口播→图文→直播切片。
  - 平台矩阵：抖音/视频号/小红书/B站/快手，按平台调标题和封面。
  - 深度矩阵：30秒知识层拉新→经验层建信任→认知层建壁垒。
- **选题来源**：①自己评论区/私信里反复被问的问题；②同行评论区里观众在抱怨什么；③搜索联想词、巨量算数、行业新闻。

## 6. 五个选题错误

1. 只有主题没有结构（没钩子、没行动号召）。
2. 只有六维没有根（形式花哨但与定位/变现脱节）。
3. 追无关热点（打乱标签）。
4. 0粉就做认知层（门槛高没人看）。
5. 选题靠"一条条想"，不建库、不批量。

## 7. 30分钟建库实操

1. 从真实感挖：3个高峰+3个低谷+3个识人踩坑+3个行业观察 = 12条。
2. 从专业度挖：新手最常问的5个问题+最容易踩的5个坑+最想纠正的3个误区 = 13条。
3. 从价值供给挖：同行评论区问得最多的5个问题 = 5条。
4. 用黄金公式补结构，用六维扩变体，按"引流/信任/变现/人设"分类入 `assets/templates/topic-library.md`。
5. 保持库里始终有 30 条储备，拍完划掉，每周补新。

> 免费版交付边界：一次给 3 条可直接拍的完整选题 + 母题清单；30+ 成库选题、行业案例库属于付费交付。
