# 校园新媒体获客方法论 · Agent Skill

> 给驾校 / 教培 / 运营商 / 校园联盟创始人 / 校园品牌 / 校园公司 / 校园供应链 / 劳务派遣 / 有付费能力的大学生创业者等**校园生意老板、操盘手与校园创业者**：用豆包（或兼容 Agent）免费装上这套 Skill，按「先定位 → 再选题 → 再开拍」出短视频获客稿。  
> 不是涨粉教程，是拿**精准客资**的开箱流程。

本仓库来自账号 **@帆总不累**（长沙校园新媒体实战）的开源引流版。你可以先免费用；用了本 Skill 或装了 Grok Bot 之后卡住，可进私域 498 答疑社群找本人答疑；觉得好用、卡在转化或想跟人一起做，再通过公域进私域了解付费产品——开源不硬推微信号。

## 60 秒上手（豆包）

1. 一键安装：

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/fl5532805-afk/campus-newmedia-ip/main/scripts/install_campus_skill.sh)
```

2. **新开一个会话**，直接说你的任务，例如：  
   「我是长沙驾校老板，本人出镜，客资要留电话，帮我写 3 条恐惧获客口播。」
3. Skill 会按五过程走：IP 定位 → 选题（开源版一次 3 条可拍）→ 四段式口播 → 封面标题 → 合规扫描 → 矩阵建议。

开工前尽量一次给齐 5 个信息：行业、出镜人设、产品与报价、目标受众、发布平台与条数。缺什么它会问你，不要空猜。

## 仓库里有什么

- `SKILL.md` — 主流程（给 Agent 读）
- `references/` — 定位 / 选题 / 四段式 / 恐惧获客 / 合规等
- `assets/templates/` — 可填空模板
- `assets/examples/` — 驾校 / 劳务 / 代运营恐惧获客示例
- `scripts/` — 安装器、选题矩阵、合规词扫描

## 常用命令

```bash
# 批量选题（需 brief.json）
python3 scripts/topic_matrix.py --brief brief.json

# 发布前合规扫描（命中即改，改完重扫）
python3 scripts/check_compliance.py script.txt
```
